# Glossary

Terms used when talking about Plasma Controller and Blood Bikes Wales operations. Definitions stay short and free of implementation detail unless needed for clarity.

| Term | Meaning |
|------|---------|
| Plasma Controller | This web app: the tool controllers use to manage jobs |
| Blood Bikes Wales / Beiciau Gwaed Cymru | The charity that runs the volunteer medical courier service |
| Controller | Volunteer (or staff) who takes hospital calls and dispatches riders |
| Rider | Volunteer courier who collects and delivers items |
| Job | A single courier task (reference like JB-1042) from pickup to delivery |
| Job status | Where the job is in its lifecycle: New, Assigned, Accepted, Collected, Delivered, Escalated, Cancelled |
| In progress | Informal board filter for jobs that are Accepted or Collected |
| Urgent / Routine | Priority of the job; urgent jobs need faster attention |
| Area | Geographic operating region (e.g. South Area, North Area) for jobs and riders |
| Pickup | Where the rider collects from (usually a hospital, sometimes a ward/department) |
| Delivery | Where the rider takes the items |
| Caller | Person at the hospital who phoned in the request |
| Contact number | Phone number for the caller or department |
| Contents | What is being carried (e.g. samples, notes) |
| Controller notes | Extra instructions the controller leaves for the rider |
| Google account | How controllers are expected to sign in; real Workspace checks are not wired yet |
